1. Understand FastAPI architecture

FastAPI is a Python framework for building APIs. It is built on Starlette for web functionality and uses Pydantic for data validation and serialization. Uvicorn is commonly used to run the application as an ASGI server.

Client — browser, mobile app, frontend or API client
↓ HTTP request
Uvicorn — ASGI server; accepts connections and runs the app
↓ ASGI interface
FastAPI application — matches routes and manages dependencies
↓
Starlette web layer + Pydantic data validation
↓
Your endpoint function — business logic and optional database work
↓ HTTP response
Client receives status code, headers and response body
Important: ASGI is an interface specification, not a separate server. Uvicorn is the server; FastAPI is the ASGI application. Starlette and Pydantic are underlying building blocks with different responsibilities.

Example request flow

For GET /students/101:

  1. The client sends an HTTP request.
  2. Uvicorn receives it and calls the FastAPI ASGI application.
  3. FastAPI matches the route and extracts student_id=101.
  4. FastAPI validates/converts the value according to its type annotation.
  5. Your endpoint function runs and obtains the student data.
  6. FastAPI serializes the result; Uvicorn sends the HTTP response.

3. Build your first API

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Welcome to FastAPI"}
  • FastAPI is imported from the package.
  • app = FastAPI() creates the application instance.
  • @app.get("/") registers a handler for GET requests at the root URL.
  • home() is called when that route matches.
  • The returned Python dictionary is serialized into JSON.
Try it: Run Uvicorn, then visit http://127.0.0.1:8000/. Expected response: {"message":"Welcome to FastAPI"}.

4. Path parameters and query parameters

Path parameter

Use a path parameter when a value identifies a resource, such as a student ID.

from fastapi import FastAPI

app = FastAPI()

@app.get("/students/{student_id}")
def get_student(student_id: int):
    return {"student_id": student_id}

Request: GET /students/101. FastAPI parses the path value and validates it as an integer. A value such as /students/abc fails validation.

Query parameter

Use query parameters for filtering, searching, pagination or optional settings.

@app.get("/students")
def list_students(class_no: int, city: str = "Pune"):
    return {"class": class_no, "city": city}

/students?class_no=10 uses the default city. /students?class_no=10&city=Mumbai overrides it. Here class_no is required and city is optional.

PathQuery
/students/101/students?class_no=10
Identifies a particular resourceOften filters or configures a result

5. Request bodies and Pydantic models

For a POST request, the client commonly sends JSON in the request body. A Pydantic model describes the expected fields and types.

from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class StudentCreate(BaseModel):
    name: str = Field(min_length=3, max_length=50)
    age: int = Field(ge=3, le=25)
    standard: int = Field(ge=1, le=12)

@app.post("/students")
def create_student(student: StudentCreate):
    return {
        "message": "Student received",
        "student": student
    }

Example JSON body:

{
  "name": "Rahul",
  "age": 15,
  "standard": 10
}

Pydantic validates the incoming data. Invalid or missing required fields normally result in a 422 validation response from FastAPI. Field adds constraints such as minimum length and numeric bounds.

Remember: A request model describes input. A response model can separately describe the data your API is allowed to return. Avoid exposing private fields such as password hashes in responses.

6. Practical project: Student CRUD API

CRUD means Create, Read, Update and Delete. This small example uses an in-memory list so you can focus on HTTP methods and route logic. Data is lost when the application restarts; use a database for persistent storage.

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class Student(BaseModel):
    id: int
    name: str = Field(min_length=3)
    age: int = Field(ge=3, le=25)
    standard: int = Field(ge=1, le=12)

students: dict[int, Student] = {}

@app.post("/students", status_code=201)
def create_student(student: Student):
    if student.id in students:
        raise HTTPException(status_code=409,
                            detail="Student already exists")
    students[student.id] = student
    return student

@app.get("/students")
def get_students():
    return list(students.values())

@app.get("/students/{student_id}")
def get_student(student_id: int):
    student = students.get(student_id)
    if student is None:
        raise HTTPException(status_code=404,
                            detail="Student not found")
    return student

@app.put("/students/{student_id}")
def replace_student(student_id: int, student: Student):
    if student_id not in students:
        raise HTTPException(status_code=404,
                            detail="Student not found")
    if student.id != student_id:
        raise HTTPException(status_code=400,
                            detail="ID in body must match URL")
    students[student_id] = student
    return student

@app.delete("/students/{student_id}",
            status_code=204)
def delete_student(student_id: int):
    if student_id not in students:
        raise HTTPException(status_code=404,
                            detail="Student not found")
    del students[student_id]
    return None

Test in Swagger

  1. Run uvicorn main:app --reload.
  2. Open /docs.
  3. Use POST /students with {"id":101,"name":"Rahul","age":15,"standard":10}.
  4. Use GET /students and GET /students/101.
  5. Use PUT /students/101 with a complete replacement body.
  6. Use DELETE /students/101, then GET it again to see the 404 response.

Why use a dictionary here? It makes lookup by ID straightforward. It is still temporary memory storage, not a substitute for a database.

7. Intermediate FastAPI topics

Routing

APIRouter

Split endpoints into modules such as students, teachers and attendance. Include routers in the main application.

Validation

Response models

Use response_model to document, validate and filter the response structure.

Errors

HTTPException

Return meaningful HTTP errors, for example 404 when a record is missing or 409 for a conflict.

Reuse

Dependency injection

Use Depends() to share logic such as authentication checks or database session creation.

Web layer

Middleware

Run logic around requests and responses, for example request timing or request ID handling.

Browser

CORS

Configure allowed frontend origins, methods and headers when browsers call your API from another origin.

Dependency injection example

from fastapi import FastAPI, Depends

app = FastAPI()

def common_info():
    return {"application": "School API"}

@app.get("/about")
def about(info: dict = Depends(common_info)):
    return info

FastAPI calls the dependency and provides its result to the endpoint. Dependencies can themselves have dependencies.

10. Top 20 FastAPI interview questions and answers

Open each question to reveal a concise answer. Practice explaining the answer in your own words and giving a small code example where appropriate.

01. What is FastAPI?

FastAPI is a modern Python web framework for building APIs. It uses Python type hints, supports asynchronous endpoints, validates data through Pydantic, and generates OpenAPI documentation automatically.

02. What are the main advantages of FastAPI?

Automatic request validation, automatic interactive API documentation, type-hint-based development, dependency injection, async support and strong performance. Actual performance depends on the application and its dependencies.

03. What is Uvicorn?

Uvicorn is an ASGI server. It runs an ASGI application such as FastAPI and handles incoming network connections and HTTP protocol communication.

04. What is ASGI, and how is it different from WSGI?

ASGI is the Asynchronous Server Gateway Interface, an interface between an application server and a Python web application. WSGI is the older synchronous-oriented interface. ASGI supports asynchronous applications and protocols such as WebSockets.

05. What is Starlette's role in FastAPI?

Starlette provides core web capabilities used by FastAPI, including routing, request and response handling, middleware and WebSocket support.

06. What is Pydantic?

Pydantic is a Python data validation and serialization library. FastAPI uses Pydantic models to describe and validate structured request data and to help serialize data.

07. What is the difference between path and query parameters?

Path parameters are part of the URL path and commonly identify a resource, such as /students/101. Query parameters follow ? and commonly filter or configure a request, such as /students?class_no=10.

08. How do you receive a JSON request body?

Define a Pydantic model and declare it as a parameter in an endpoint function. FastAPI reads the request body, validates it and supplies the model instance to the function.

09. What is dependency injection in FastAPI?

Dependency injection lets an endpoint declare what it needs using Depends(). FastAPI resolves the dependency and supplies its result. It is useful for shared logic, authentication and database sessions.

10. What is the difference between async def and def endpoints?

async def defines a coroutine and can use await for awaitable operations. A normal def is synchronous; FastAPI runs ordinary synchronous path operations in a thread pool. Choose based on the libraries and operations being used.

11. What is the difference between PUT and PATCH?

PUT conventionally replaces a resource representation. PATCH applies a partial modification. The exact behavior should be defined and documented by the API.

12. What is HTTPException?

HTTPException is used to stop request processing and return an HTTP error response with a status code and detail message, for example a 404 when a student does not exist.

13. What is a response_model?

response_model declares the expected response schema. FastAPI uses it for response validation, serialization and documentation, and it can filter fields that should not be returned.

14. What is APIRouter?

APIRouter groups related endpoints so an application can be split into modules. For example, student routes and teacher routes can live in separate files and be included in the main app.

15. What is middleware?

Middleware is code that runs around request handling. It can inspect or modify requests and responses, measure execution time, add headers or implement cross-cutting behavior.

16. What is CORS?

Cross-Origin Resource Sharing is a browser security mechanism. A FastAPI application can configure which origins, methods and headers are allowed to access it from browser-based frontends.

17. How does FastAPI generate Swagger documentation?

FastAPI generates an OpenAPI schema from route declarations, type annotations and models. Swagger UI is commonly available at /docs, and ReDoc at /redoc.

18. How do you handle authentication in FastAPI?

Use a secure authentication design with password hashing, token or session verification, and backend authorization checks. FastAPI provides security utilities and dependency patterns; the application must implement and configure the actual security policy correctly.

19. How do you test FastAPI endpoints?

Use pytest with FastAPI's TestClient to send requests to the application and assert status codes and response data. Override dependencies to isolate databases or external services during tests.

20. How do you prepare a FastAPI application for production?

Use production server configuration, environment-based settings, secure secret management, HTTPS, database migrations, logging, monitoring, tests, appropriate worker/process management and a deployment strategy. Disable development reload mode.
